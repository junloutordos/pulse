## Data

`data/reference/` is built by `pipeline/scripts/build_reference.py` from the municipality shapefile in [altcoder/philippines-psgc-shapefiles](https://github.com/altcoder/philippines-psgc-shapefiles) (MIT licence), which is built from public data and updated with PSA PSGC changes (the repository states PSGC as of 31 December 2023). It holds 73 Caraga cities and municipalities with official 10-digit PSGC codes. Tile hexagons are generated by this project. Confirm the PSGC quarter against the current PSA publication before using real data. OCHA's [Philippines subnational boundaries](https://data.humdata.org/dataset/cod-ab-phl) (CC BY-IGO, updated 28 May 2026) is an alternative source with the same PSGC codes.
